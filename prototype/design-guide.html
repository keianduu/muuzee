Global visual language

Art first.
UI stays quiet.

4px Grid White / Greige Surface Artwork provides color 14 / 12 / 10 Type No scroll-linked image scaling

Muuzeeのページ展開で共通利用するデザインルール。ページ固有のUIより先にこのガイドを参照し、 色・文字・画像・Motion・Navigation・Masonryの挙動を揃える。 明示的な仕様変更がない限り、Global Ruleはページごとに独自解釈しない。

Foundation

Brand / Surface

UI自体の色は抑え、作品・展示画像がページの主な色になる。背景は白を基本に、セクション差をWarm / Greigeでつける。

Spacing

基本は4px Grid。8 / 12 / 16 / 24 / 28 / 32 / 40 / 48…を優先する。光学的に不自然な場合のみ微調整する。

Shape

UI Surfaceは12〜28pxの角丸を用途に応じて使う。作品画像そのものには装飾的な角丸を付けすぎない。

Shadow

ShadowはNavigationや浮いたSurfaceの階層表現に限定。作品画像・展示メイン画像には原則Shadowを付けない。

Responsive

主な境界は720px / 980px。DesktopのShellは最大1240px、画面端余白はDesktop 32px / Tablet 20px / Mobile 18pxを基本とする。

Typography

One sans-serif system

日本語・英字ともゴシック系で統一。視認性を担保しつつ、補足情報まで大きくしすぎず情報密度を保つ。

Images

Preserve the artwork

作品・展示画像はUIに合わせて無理にトリミングしない。画像の縦横比を尊重し、画像そのものをコンテンツとして扱う。

Portrait / Poster

自然比率を維持。縦長画像は高さを基準に収め、必要なら左右に白余白を許容する。

Landscape / Exhibition Hero

横長画像も全体を表示。画像の表示高さにContent Sheetの開始位置を自然に合わせる。

Default Natural ratio first

width:auto; height:auto; を基本にし、作品の比率を崩さない。

Exhibition hero max-height: 70svh

白背景、max-width:100vw、object-fit:contain、Shadowなし。

Exception Cover only by intent

Brand Heroなど「トリミングを前提とした写真」だけcoverを使う。

/* Important: mobile browser UI must not resize artwork while scrolling */
.exhibition-hero img {
  width: auto;
  height: auto;
  max-width: 100vw;
  max-height: 70svh;
  object-fit: contain;
}

/* Do NOT recalculate artwork size from window.innerHeight on scroll/resize. */
Motion

Quiet, slow, intentional

Motionはコンテンツ理解を邪魔しない。常時動く演出やスクロール連動の拡大縮小より、初期表示とUI状態変化に限定する。

Brand Hero only Initial zoom 1.08 → 1.00 / about 10s
Header state transition

Sheet到達時の背景・文字・Shadow切替は約260ms。短く、目立たせすぎない。

No scroll-linked artwork zoom

スクロール量、innerHeight、ブラウザBottom Barの出入りで画像サイズを変更しない。

Reduced motion

prefers-reduced-motion: reduce ではHero Animationと不要なTransitionを停止する。

Navigation

Shared navigation states

Header / Bottom Navigationはページごとに作り直さず共通利用する。Headerのロゴ・お知らせ・MyPage Avatar・Hamburgerは全ページで統一し、Heroの有無に応じて表示状態だけ切り替える。

Header Reveal

Hero上では透明。白いContent SheetがHeader領域まで到達したら、Headerを前面へ出して白背景 / Inkへ切り替える。

Bottom Navigation

6項目を共通利用：ホーム / 展示会 / アーティスト / 美術館 / マップ / 保存。Mobileでは画面下部に固定し、Safe Areaを考慮する。

Content surface

Hero + Rising Sheet

Heroを持つページでは、画像と本文を別レイヤーとして扱い、白いContent Sheetが下からHeroを覆う構造を共通パターンとする。

Exhibition

Content begins on the sheet.

タイトル、会場、本文などの情報は画像上に重ねすぎず、Sheet側に集約する。

Status

Compact metadata

ステータスは小さなPillで統一。展示一覧と展示詳細で同じ見た目を使用する。

Masonry

Natural ratio collection

ArtWall等のMasonryは作品画像の自然比率を活かす。装飾的なカード化を避け、作品の集合そのものをVisual Profileとして見せる。

Layout algorithm

各画像のnaturalWidth / naturalHeightを読み、最も高さの低いColumnへ順に配置するTrue Masonryを基本とする。

Preview behavior

Home等のPreviewでは高さを固定してOverflowを隠し、下端Fadeは必ず親Sectionと同じ背景色へ溶かす。

Global rules

Rules for every page

新規ページを作る際、まずここを継承する。ページ固有のデザインはこのGlobal Ruleを壊さない範囲で追加する。

1. 4px Grid

Spacing・高さ・Paddingは4px単位を優先。光学調整は例外として許容。

2. Art first

作品画像をUI装飾より優先。UIの色数を抑え、画像が色を担う。

3. 14 / 12 / 10

Primary 14px、Secondary 12px、英字・Label・Status等のTertiary 10px。

4. Shared navigation

Header / Bottom Navigationは共通Componentとして扱い、ロゴ・右上アクション・アイコンを含めページごとに別Versionを作らない。

5. Stable images

実機Browser UIの出入りで画像サイズが変わらないこと。scroll/resizeによる動的画像Scaleは禁止。

6. Quiet motion

Motionは初期Hero・Navigation状態変化など、意味がある場所だけに限定。

7. Natural ratios

展示・作品画像は自然比率を維持。Coverは意図的なBrand Photoなどに限定。

8. Surface hierarchy

White → Warm → Greigeの面差で階層を作り、Shadowは必要最低限。

Shared Save Control

一覧 / Preview / 関連コンテンツのSaveは muuzee-save-control.css / js を共通利用する。Card Wrapper直下にDetail Link <a> とSave <button> をSiblingで配置し、Save ControlをLinkの内側へ入れない。未保存はWhite Surface / Ink、保存済みはWhite Surface / Terracotta Filled Bookmark。Save ON時は短いSpring + Ring feedbackを使い、prefers-reduced-motion を尊重する。

This document is the current global visual reference for Muuzee prototype pages. Page-specific exploration may differ, but a Global Rule change must be reflected here deliberately.

Shared Save Control structure

保存可能なCardは、Card Wrapper直下にDetail Link <a> とSave <button>をSiblingとして配置する。Save Controlを<a>の内側には置かない。未保存はSolid White / Ink、保存済みはSolid White / Terracottaの塗りBookmarkを使用する。

Shared ArtWall

ArtWallは現在のMyPage / HOMEで利用している既存Markup・CSS・JSをそのまま共通利用する。ArtWall EditではArtWall本体のVisual Ruleを再実装せず、Checkbox / Drag / Drop Placeholderなど編集時だけ必要な差分UIのみpage-specificに追加する。

Shared Map UI

Pin / Tooltip / Tooltip内Save / Tooltip中央移動は muuzee-map-ui.css / muuzee-map-ui.js を共通利用する。TOPとMap Discoveryで個別実装しない。TOP Mapは座標を持つExhibitionを表示し、MapページはExhibition / Museumの表示Modeを切り替えられる。

Shared Hamburger Navigation

Global HeaderはLogo / Account Action / Hamburgerを共通利用する。ログイン時はProfile Avatar、未ログイン時はLogin Iconを表示する。NoticeはHeaderに置かず、Hamburger Drawer上部の独立CTAとして扱う。Hamburgerは円形の静かなHeader Actionとし、Drawerは右から左へ開く。Global実装は muuzee-global.css / muuzee-global.js を利用し、ページごとに複製しない。

Hamburger / Header Layering

Drawer / ScrimはGlobal Headerを覆わずHeader直下から開始する。Desktop Headerは76px、Mobile Headerは62pxを基準にし、Menu表示中もLogo / MyPage Avatar / Hamburger / Header下線を常時視認可能にする。HeaderをDrawer / Scrimより上位Layerとして扱う。

Hamburger Navigation Groups

Notice CTAはDrawer上部に置き、Warm Surface + Radiusを使用する。Border / Box Shadowは持たない。ログイン時のPersonal Navigation（My Art / 保存 / ログアウト）は通常Navと同じWhite Surface / Dividerを使い、左側の短い太いTerracotta Markerのみで区別する。未ログイン時はPersonal Navigationを表示せず、同じ位置にLogin / Register導線を置く。

Guest / Login Prototype

Prototypeのログイン状態はURLの ?loginID=... とPrototype User Storeで判定する。未ログインでもCard / DetailのSaveと保存一覧は利用可能とし、Save成功後にBottom Navigation付近から会員導線を静かにSlide Up表示する。Footerの保存は未ログインでもSavedへ遷移する。Savedの未ログイン表示ではProfile HeaderとSaved / Seen / Favorites Navigationを表示せず、展示会 / 美術館 / アーティスト / 作品のCategory以降を表示する。My Art / Profile Settingsはログイン導線を開き、DetailのSeenは未ログイン時に表示しない。Login / Register PopupはShared ComponentとしてGlobal実装し、ページごとに複製しない。ログイン中のHamburger Personal NavigationはMy Art / 保存 / ログアウトとする。

Personal Actions / Section CTA

DetailのSave / Seenは muuzee-personal-actions.css / js を共通利用する。Section Title右側の「すべて見る →」「詳細検索 →」「保存を見る →」などは .muuzee-section-cta を共通利用し、Ink Pill / White Text / Secondary 12pxで統一する。

Typography implementation guard

本文系はPrimary 14px / Secondary 12px / Tertiary 10pxを基本とする。Page Title 24px、Section TitleはDesktop 28px / Mobile 22px。Hero Display 54pxは明示されたpage-specific用途のみ。Layout都合で9px / 11px / 13px / 15px / 17px / 18px等を追加しない。新しいTypography Tokenが必要な場合はGlobal Design Ruleとして先にGuideを更新する。

Global Footer Navigation

6項目を共通利用：ホーム / 展示会 / アーティスト / 美術館 / マップ / 保存。各画面で同一Order / Icon languageを維持し、現在地のみActive Stateを表示する。MobileではBottom Navigationとして固定し、ページ固有の独自Footer Navigationを作らない。

Interactive semantics

Card NavigationとSave / Seen等のActionは独立したInteractive Elementとして扱う。<a> の中に <button> を入れない。Focus Visibleを保持し、Keyboard / Touchで周辺Card遷移を誤発火させない。
